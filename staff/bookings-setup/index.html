At a glance

Set up each workshop as one group service on one shared booking page. Set up the first one carefully, then duplicate it for the rest. Back to the Staff guide.

Have these open side by side
  • The Excel sheet: filter Status = Confirmed and Bookings = Not set up. Each row gives the workshop, technician, date, time, room, places and description.
  • Microsoft Bookings: book.ms, or Bookings from the left bar in Outlook on the web.
Golden rules. Set Maximum attendees above 1 before the first save (a service saved with 1 can never become a group workshop) · never edit or duplicate the default service Bookings creates · one date range per session.

Field names follow the current Bookings screens. If a label looks slightly different, match it by meaning.

1 · Open the shared booking page

  1. Go to book.ms.
  2. Open the shared page CSM GCD Stage 2 Digital Labs Technical Workshops.
✅ Check: you're on a Shared booking page. A Personal page only does 1-to-1 meetings.

2 · Staff, business hours and booking page default

Staff (left menu → Staff)

  • Add every technician named in the Technician column.
  • Click each name → untick Events on Office calendar affect availability, so their own meetings can't hide a workshop slot.

Business hours (left menu → Business information)

  • Check the hours cover 09:00–17:00, Monday to Friday.

Booking page default (left menu → Booking page → Default scheduling policy)

The safety net: every workshop starts closed. Only the session dates you add in Step 4 open up.

4 · Availability options

This makes the workshop bookable only on its session dates and times. It works in three layers:

Booking page = Not bookableStep 2: everything starts closed
This workshop: Default scheduling policy toggle ❌ offIt uses its own settings. Left on, it copies Not bookable and no dates appear
This workshop: Not bookable + one date range per sessionOnly those sessions open
FieldWhat to enter
Time increments3 hours
Minimum lead time24 hours (also the latest a student can cancel)
Maximum lead time365 days
General availabilityFirst change Bookable when staff are free → Not bookable

Add each session

  1. Check General availability reads Not bookable.
  2. Click Set different availability for a date range.
  3. Set Start and End (inclusive) to the same day: the session date. ⚠️ Dates may show month/day/year: 12/4/2026 = 4 December.
  4. Choose Custom hours (recurring weekly).
  5. On the session day only, click + and set the time, e.g. 10:00 AM – 1:00 PM.
  6. Leave every other day on Not bookable.
  7. Repeat 2–6 for each session (each row of that workshop in the sheet).
  8. Click Save changes (bottom right) and wait for the panel to close.
🔍 Test straight away: open the service's own Service booking page link (Services → the workshop → Overview) in a private window. Don't judge by the Bookings calendar: it only shows sessions once someone has booked. The workshop shows only its session dates. Every weekday showing? Not saved: save again. No dates? The toggle is still on. Still wrong? Wait 5 minutes and reload.

7 · Notifications

Three messages, the same text for every workshop. Bookings adds the workshop name, date and time itself. The room isn't in the emails, so the texts point students to the workshops website.

SettingChoose
Text messages❌ Off
Notify the business❌ Off
Send a meeting invite to the customer✅ On
Email confirmation → Add additional informationPaste Text A
Add an email reminderCustomer · 1 day before · Text B
Add a follow-up emailCustomer · 15 minutes after · Text C

The reminder goes out 1 day before and can't be set to a specific time. The Technical Coordinator checks sign-ups before that point, so a cancelled session never gets a reminder.

📩 Text A · Confirmation

Thanks for booking a CSM GCD Stage 2 Digital Labs workshop 🙌 Your workshop, date and time are shown in this email. You'll find the room on the workshops website.

Before you come: • Bring your laptop and charger, and the files you're working on. • Arrive on time: sessions start promptly and run for 3 hours.

Can't make it? Cancel at least 24 hours before, using the cancel link in this email, so your place can go to someone else. Booking is a commitment: not turning up without cancelling isn't an option.

⏰ Text B · Reminder (1 day before)

Reminder: your CSM GCD Stage 2 Digital Labs workshop is tomorrow ⏰ The time is in this email; the room is on the workshops website.

Bring your laptop, charger and your files. If you can no longer come, cancel now using the link in this email so someone else can take your place.

💬 Text C · Follow-up (15 minutes after)

Thanks for coming to today's Digital Labs workshop 👏 How did it go? Tell us in the short feedback form below: it only takes 2 minutes.

Feedback form: https://forms.cloud.microsoft/e/9mQ4fCppEF

Want more help with the software? Drop into Digital Labs or book a 1-to-1 with a technician.

8 · Duplicate for every other workshop

  1. Services → hover over the finished workshop → Duplicate.
  2. The copy keeps the group setting, Not bookable, the notifications and all fixed settings.
  3. Change only: service name · description (with its 📍 Location line) · notes · maximum attendees · staff · date ranges (delete the copied ones, add one per session).
  4. Save changes, test in a private window, then repeat for every confirmed workshop.
  5. In the Excel, set Bookings to Live on each of its rows.

9 · Publish and test

  1. Left menu → Booking page → tick Require a Microsoft 365 account from my organization to book.
  2. Click Save and publish.
  3. Open the booking page in a private window, book one session with a test account, then cancel it from the confirmation email.
  4. Tell the Stage 2 Leader the workshop is live.
✅ Check: every workshop shows only on its own session dates, with the right number of places, and the cancel link works.
