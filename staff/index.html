Overview

Three roles run the optional Digital Labs workshops for BA GCD Stage 2. One shared Excel sheet tracks every session. All three roles have admin rights on the MS Bookings page, so any of them can make changes. The same process runs every year.

Start here: what's your role?

I'm the Stage 2 Leader →

The plan: which workshops, when, which unit. Propose, share, announce.

I'm the Technical Coordinator or a technician →

Confirm details, Celcat, co-manage Bookings, check sign-ups and cancel if needed.

I'm Course Admin support →

Set up each workshop in Bookings, collect and share feedback.

What each role does, step by step

Stage 2 Leader

  1. Add proposed sessions to the Excel sheet (one row per session). Status: Proposed.
  2. Share the sheet with the Technical Coordinator.
  3. When Bookings shows Live, announce the workshop to students (Teams, Moodle, website).
  4. If a session is cancelled, you'll hear from the Technical Coordinator. No action unless students ask.

Technical Coordinator + technicians

  1. Check each session with the technician: fill in Date, Room, Max places and edit the Description if needed.
  2. Set Status to Confirmed or Changes needed.
  3. Add each confirmed session to Celcat as a room booking (no student groups). Set In Celcat to Yes.
  4. Co-manage the MS Bookings page with Course Admin: you can make changes directly (see Changes).
  5. Before the student reminder goes out (24 hours before each session): check sign-ups and cancel if under 25% (see The check before the reminder).

Course Admin support

  1. Filter the sheet: Status Confirmed + Bookings Not set up.
  2. Set up each workshop in MS Bookings with the Bookings setup instructions. Duplicate the template service; change name, description (location as the last line), places, staff and dates.
  3. Test it, then set Bookings to Live on each of its rows.
  4. Collect feedback: download the feedback form responses and share them with the Stage 2 Leader and the Technical Coordinator's team.

To cancel

  1. Open the session in the Bookings calendar → Cancel.
  2. Paste the cancellation message below.
  3. Tell the Stage 2 Leader.
  4. Set Status and Bookings to Cancelled on that row.

Sorry, this Digital Labs workshop has been cancelled because not enough people signed up. Check the workshops website for other sessions, or book a 1-to-1 with a Digital Labs technician.

Bookings stay open until 24 hours before, so one or two late sign-ups can arrive after the check. That's accepted.

  • Can't come? Students cancel with the link in their confirmation email, at least 24 hours before. The place opens up for someone else.
  • Session cancelled (under 25%)? Students get the cancellation message by email instead of a reminder.
  • Workshop full? Students check back closer to the date, as places free up when people cancel.

Changes and golden rules

Something changes before Bookings is live? Just edit the Excel and update Last updated.

Something changes after Bookings is live (date, time, room)? Bookings does not move existing bookings, so:

  1. Update the Excel (and Last updated).
  2. Change the service in Bookings (Technical Coordinator or Course Admin).
  3. Email the students who already booked (their names are in the Bookings calendar).
  4. Tell the Stage 2 Leader, who updates the website.
Golden rules
  • One shared Excel file: never work from a downloaded copy.
  • A workshop is announced only when Bookings is Live.
  • Location goes at the bottom of the Bookings description, not in the Location field.
  • Workshop names in Bookings match the website titles exactly.
  • Check sign-ups before the reminder goes out, never after.

Every year: same process

Workshops roll over each year. Nothing is rebuilt from scratch.

  1. Stage 2 Leader: copy the Excel for the new year, keep the workshops that worked (use the feedback), add or drop others. Reset Status to Proposed, In Celcat to No, Bookings to Not set up.
  2. Technical Coordinator + technicians: confirm as in steps 3–4.
  3. Course Admin: reuse the existing Bookings services. Delete last year's date ranges, add the new ones, update description, places and staff. New workshops: duplicate a service.
  4. Then steps 5–9 run as before.
